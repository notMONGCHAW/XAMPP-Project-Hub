# INSTALLATION INSTRUCTIONS

## For GitHub Users - Quick Setup

### Step 1: Download
Click the green **"Code"** button → **"Download ZIP"**

### Step 2: Extract
Unzip the downloaded file to any location on your computer

### Step 3: Copy Files
Copy **ALL files** from the extracted folder into your XAMPP htdocs directory:
- **Windows:** `C:\xampp\htdocs\`
- **Linux:** `/opt/lampp/htdocs/`
- **Mac:** `/Applications/XAMPP/htdocs/`

### Step 4: Replace
When asked, **REPLACE** the existing `index.php` file. This is important!

### Step 5: Done!
1. Start XAMPP Control Panel
2. Start Apache
3. Go to `http://localhost`
4. Your dashboard is ready!

## What Gets Installed

✅ `index.php` - Redirects to the dashboard (REPLACES existing)  
✅ `apps-dashboard.php` - The main dashboard file  
✅ `README.md` - Full documentation  
✅ `LICENSE` - MIT License  
✅ `CHANGELOG.md` - Version history  

## All Your Existing Projects Stay Safe

- Your `dashboard/` folder stays untouched
- All your app folders remain exactly as they are
- XAMPP tools like phpMyAdmin still work
- Everything is 100% reversible
